# Kishi Switch 0.1.3 — licence et attribution

Cette version applique **PolyForm Noncommercial 1.0.0** au code propre du projet
et ajoute les deux `Required Notice:` : attribution de Maugrey et lien vers le
code d'origine. Les licences des bibliothèques, dont Shizuku API sous MIT,
restent distinctes et sont incluses dans l'APK.

Un bouton **« Licences et attribution »** permet de consulter les textes hors
ligne et d'ouvrir le dépôt dans le navigateur. Les sources et une archive des
mentions légales accompagnent cette livraison.

Installer l'APK par-dessus la 0.1.2. Le moteur de remappage, le relais HID,
les réglages et les validations sont conservés. Le fonctionnement dans Guild
Wars a été confirmé par l'utilisateur en 0.1.2 ; cette livraison ne prétend
pas constituer un nouvel essai sur son téléphone.

Les archives de sources contiennent uniquement les fichiers enregistrés dans
Git. Les métadonnées de contrôle de version ne sont plus ajoutées à l'APK.

Contrôles : compilation et signature vérifiées, 17 tests du moteur conservés
sans échec, Android Lint sans erreur, neuf documents légaux présents et vérifiés
dans l'APK. Aucun nouvel essai sur le téléphone pour cette mise à jour de licence.
