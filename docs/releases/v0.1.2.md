# Kishi Switch 0.1.2 — relais HID

Le test de transmission de la 0.1.1 était accepté par Android sans produire d’action dans Guild Wars. Cette version remplace la réinjection des événements Android par une manette HID, avec lecture de la Kishi via Shizuku sans root. Le prototype de ce transport a fonctionné sur le OnePlus avec Guild Wars ; les inversions de l’APK intégré restent à confirmer dans les essais guidés.

Installer l’APK par-dessus la version précédente. Le profil et les réglages sont conservés. Relâcher les commandes au démarrage de chaque essai. Les anciennes validations sont réinitialisées pour vérifier le nouveau transport.

L’accessibilité n’intercepte plus les commandes. Elle affiche la pastille et commande la suspension hors du jeu, pendant la saisie et au verrouillage. M2 reste indisponible dans cette version ; utiliser l’overlay.

Validation : compilation signée, 17 tests Kotlin réussis et Android Lint sans erreur. Voir la notice et le compte rendu joints pour les essais sur téléphone et les limites restantes.
