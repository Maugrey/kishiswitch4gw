# Kishi Switch 0.1.4 — English / Français

## English

This release provides an English README, user guide and validation report,
alongside their French versions. Attribution explanations in `NOTICE` and
`THIRD_PARTY_NOTICES.md` are bilingual, including the copies available offline
in the APK. Official license texts and both `Required Notice:` lines are unchanged.

The app interface remains in French. The English user guide includes the French
button labels so that you can follow the setup steps.

Install `KishiSwitch-0.1.4.apk` over your existing version. Controller behavior,
settings and validations from 0.1.2 or 0.1.3 are retained. A new version is provided
so that the APK includes the updated notices.

Checks: signed build successful, same signing certificate, nine embedded legal
documents verified, local documentation links checked, Android Lint without
errors. Gradle reused the 17 successful engine test results because the engine
is unchanged. No new phone test was performed for this documentation update;
gameplay confirmation still refers to 0.1.2.

Download `NOTICE.md` for the English user guide and `VALIDATION.md` for the report.
`NOTICE` without an extension contains the required attribution. Source and
license archives are included, along with SHA-256 checksums.

## Français

Cette version fournit un README, une notice et un compte rendu en anglais,
avec leurs versions françaises. Les explications de `NOTICE` et de
`THIRD_PARTY_NOTICES.md` sont bilingues, y compris les copies consultables hors
ligne dans l'APK. Les licences officielles et les deux lignes `Required Notice:`
sont inchangées.

L'interface reste en français. La notice anglaise reprend les libellés français
des boutons pour permettre de suivre la configuration.

Installer `KishiSwitch-0.1.4.apk` par-dessus la version précédente. Le comportement
de la manette, les réglages et les validations de la 0.1.2 ou de la 0.1.3 sont
conservés. Cette version permet de distribuer les nouvelles mentions dans l'APK.

Contrôles : compilation signée réussie, même certificat, neuf documents légaux
embarqués vérifiés, liens locaux contrôlés, Android Lint sans erreur. Gradle a
réutilisé les résultats des 17 tests du moteur réussis, car le moteur est inchangé.
Aucun nouvel essai sur le téléphone pour cette mise à jour documentaire ; la
confirmation du fonctionnement en jeu concerne toujours la 0.1.2.

Télécharger `NOTICE.fr.md` pour la notice française et `VALIDATION.fr.md` pour le
compte rendu. Le fichier `NOTICE` sans extension contient l'attribution requise.
Les archives de sources et de licences sont incluses, avec les empreintes SHA-256.
